# Free VPN

Free VPN Android app (com.freevpn.client) — v1.0

- Fetches the live [VPN Gate](https://www.vpngate.net/) public server list (hundreds of free OpenVPN servers, no account needed)
- One-tap connect, auto-failover to the next server if one fails
- Burmese UI

Requires the free **OpenVPN for Android** app (Play Store, `de.blinkt.openvpn`) — the tunnel runs through its public external API.
